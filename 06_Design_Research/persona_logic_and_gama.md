# Persona 前置分析与 GAMA 扩展逻辑

## 证据链

`可核实证据 → 行为模式 → Persona 原型 → GAMA 规则 → 情景实验`

证据包括课程记录、公开建筑信息、校区边界和路网。行为模式只表达时间刚性、活动节点、移动范围、停留和环境响应，不构造虚假的个人故事。

## Stanford Town 的迁移边界

可以迁移：状态机、活动链、空间图、目的地选择、路径规划、停留机制、环境响应和情景比较方法。

必须重建：同济建筑与路网、校门与宿舍、课程周次与节次、跨校区边界、步行网络、气候暴露、拥挤参数和实际活动节点。

禁止直接迁移：虚构人物传记、未经验证的个人偏好、精确个人路线、Stanford Town 的空间尺度和同济学生的真实课表推断。

## 从 6 个原型扩展样本

每个原型定义一组参数中心，再从分布中抽样生成多个 Agent：

| 参数 | GAMA 用途 | 示例 |
|---|---|---|
| `discipline_affinity` | 目的地选择权重 | 对实验楼、研究楼的偏好 |
| `schedule_rigidity` | 是否必须按时抵达 | 课程型高，弹性自习型低 |
| `distance_weight` | 距离对目的地的影响 | 路程越远，选择概率下降 |
| `weather_weight` | 对高温、降雨的响应 | 高值更偏好室内或遮阴路径 |
| `dwell_time` | 活动持续时间分布 | 实验、就餐、自习的不同范围 |
| `cross_zone_prob` | 跨建筑群 / 跨校区概率 | 海洋、健康、能源原型可不同 |
| `walk_speed` | 路网移动速度 | 作为个体差异而非固定常数 |
| `random_seed` | 复现实验和比较差异 | 多种 seed 对比稳健性 |

例：环境 Agent 提高 `weather_weight`，降低户外停留时长；化学 Agent 提高 `schedule_rigidity` 和 `lab_affinity`。所有参数必须标记 Observed、Reported、Inferred 或 Synthetic。
