# GAMA 全天模拟｜真实运行与 OBS 记录

本目录保存 2026-11-09 在 GAMA 中完成的全日模拟输出、界面截图和 OBS 实录。数据为按行为规则生成的合成 Agent 轨迹，用于比较活动链与空间指标，不是现场人流调查。

## 运行口径

- 空间范围：同济大学四平路校区全域；337 条道路、192 个候选观察点。
- 人口：1,474 个 Agent；环境 400、海洋 384、马克思主义 72、化学 351、公共管理 267。
- 时间：07:30–17:30（模型分钟 450–1050）。
- 随机性：人口生成种子 20261105；GAMA 随机种子 42。
- 运行方式：GAMA 2025.6.4，实际打开 `TongjiDailyScope.gaml` 并运行；OBS 33.0.0 采集 GAMA 应用窗口。

## 两组实际运行结果

| 情景 | 参数 | 结果 |
|---|---|---|
| 全日基线 | `enable_facilities=false` | 1,474 人完成至 17:30；73,290 条空间观测；设施到访 0 |
| 设施指标试运行 | `enable_facilities=true`；192 个候选点统一开启，每点 6 席 | 1,474 人完成至 17:30；71,331 条空间观测；设施进入事件 5,831 次；单点观测峰值 6 人 |

5,831 为进入事件总次数，不是独立访客数。候选点表中逐点去重访客相加为 5,435，跨点重复者仍会重复计入。设施指标这组用于跑通统计与画面；当前 GIS 输入仍将点位标为 `observe_only`，它不代表最终设施布点。确定学苑草坡等午休干预位置后，应按最终点位和容量重新运行。
