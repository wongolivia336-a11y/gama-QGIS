# 全天全校域 GAMA 工程包与运行核验

日期：2026-11-08  
研究：从活动链到空间图谱——环境科学与工程学科群学生行为与空间关系研究

## 本轮推导

先覆盖同济四平路校区全域，按典型工作日 07:30–17:30 推演五个核心专业的活动链；再从全天路网/空间热度、建筑到访及跨专业接触中识别重点建筑、区域与时段，最后进入局部模拟与方案比较。因此，午间只是后续可能选出的窗口，不是本轮预设的模拟边界。

## 人口与数据来源

人口固定为 1,474 个合成 Agent：环境 400、海洋 384、马克思主义 72、化学 351、公共管理 267。嘉定/沪西为主的其他专业不纳入本轮。晨间来源为 1,179 人从宿舍、295 人从校园接入点进入。

参数依据和行为推导保留在[全天 Agent 参数 Excel](../02_Data/processed/同济大学全天Agent模拟参数归类_修订版.xlsx)。课程文件共聚合 956 条课程记录；ENV、CHEM、OCEAN、MARX 匹配到 839 条，公共管理没有匹配记录，使用模型明确写出的四段参与概率 `[0.35, 0.40, 0.40, 0.30]`。课程时段用于总体日程负荷，不等于独立学生数，也不还原个人选课。

收到的 ZIP 内含 GAMA 源码、压缩日计划、人口表、课程聚合、GeoJSON 导出、CSV 结果、运行日志和截图。为便于组员复跑，压缩计划及必要模型已收录到 [`05_GAMA/full_day/submitted_package/`](../05_GAMA/full_day/submitted_package/)。原始 GUI 截图没有上传到公开仓库，因为标题栏带有本机路径；已放入指定 Figma 汇报页。

## 运行配置与结果

运行配置：GAMA 2025.6.4；07:30–17:30；10 秒一步；每分钟汇总，共 601 个时间点。人口/日计划种子 20261105，设施行为随机种子 42。设施压力测试设置 `seat`、每处容量 6；该配置是工程包本轮的实际值。

| 核验项 | 无设施吸引基线 | 192 点设施压力测试 |
|---|---:|---:|
| 全日正常完成 | 是 | 是 |
| Agent 人口守恒 | 1474 | 1474 |
| 分钟状态记录 | 601 | 601 |
| 候选点观察事件 | 73,290 | 71,331 |
| 有过模拟人群经过的候选点 | 153 / 192 | 153 / 192 |
| 设施到访人次 | 不适用 | 5,831 |
| 单处设施最大瞬时占用 | 不适用 | 6 |
| 迟到课堂到达记录 | 0 | 67 |

基线的 39 个零经过候选点表示本轮合成人群路径没有经过这些点，不表示现场没有人。192 个点全开仅作为容量/行为压力测试，产生迟到，因此不可把它当作最终设施选址。后续应在相同人口底稿与随机种子下比较选定子集。

既定主指标仍为“跨专业成功交互 / 100 名去重访客”；同时报告相遇机会数和模型设定的 60% 成功概率。单独报告成功概率会重复模型常数，不能替代点位比较。

## 执行证据边界

压缩包内的 GAMA 日志、CSV 和 `validation/verification.json` 显示两种运行都到达 17:30；本次已对汇总、状态记录、候选点数与访问指标进行交叉核对。但在当前电脑上尝试重新启动时，GAMA 出现“Different version of the models library”弹窗，未能完成独立本机复跑。因此记录为“用户提供包内运行完成、当前环境复跑受阻”，不写成“本机重新运行通过”。

连续屏幕录像没有生成。Figma 中嵌入的是工程包自带的 GAMA GUI 08:30 运行截图，以及 11:40 全校域专业移动结果预览；图像为实际工程证据，不是录屏或现场实测。
