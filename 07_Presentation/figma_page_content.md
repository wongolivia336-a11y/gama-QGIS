# Figma 新 Page 内容包

建议新建页面：`03｜课表驱动的 Student Agent`

## 页面标题

课表驱动的 Student Agent

副标题：低碳发展、环境治理与健康｜把课程任务记录转译成可运行的校园行为原型

## 第一块：数据证据

课程检索站公开字段：学期、课程名称、校区、开课学院、课程性质、星期/节次、开课周次、教室、听课专业等。

当前状态：已取得公开索引样本；直接页面/API 尚未在当前执行环境稳定批量读取。课程任务记录只能支持课程和空间分布，不能还原个人完整课表。

|---|---|---|---|

## 第三块：活动链

`到达 → 上课/实验 → 自习/数据处理 → 就餐 → 研究/讨论 → 离开或转移`

每个 Agent 至少记录：`start_time, end_time, activity_type, origin_id, destination_id, travel_mode, evidence_type, uncertainty`。

## 第四块：规则

- 时间：课程节次/周次为固定约束。
- 目的地：按活动类型选择教学、实验、图书馆、食堂和公共讨论节点。
- 路径：第一版使用距离/时间；遮阴、降雨、拥挤只有在数据或明确实验假设支持时加入。
- 多样性：同一 Agent 类型使用不同随机种子和停留时长。

## 页脚警示

`课程记录 ≠ 个人课表；Agent 轨迹 ≠ GPS；模拟热点 ≠ 真实人流。`

## 推荐视觉

白底、深蓝/墨黑正文、青绿色表示环境/健康、橙色表示化学/能源、蓝色表示教学/计算；页面采用“证据卡 → Agent 卡 → 活动链 → 限制说明”的四段结构。
