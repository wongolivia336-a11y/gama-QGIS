# 研究范围

研究场景：同济大学四平路校区全域，作为校园活动链研究与设计实验场景；先完成全日模拟，再由结果确定重点建筑/区域和时段。不直接等同于最终商业街区。

本轮 Agent 群体：环境科学与工程、海洋与地球科学、马克思主义理论、化学、公共管理五个四平路核心专业，共 1,474 名合成 Agent。嘉定/沪西为主的其他学科按用户确认不进入本轮 Agent 池。

研究问题：

- 课程时段分布与行为活动链如何共同形成全日时空节律？
- 不同专业活动和起点分配如何影响节点选择、跨区移动和停留？
- 热、雨、遮阴与休息条件在何种假设下会改变路线或停留？
- 哪些校园证据可以迁移到商业街区，哪些参数必须重新采集？

不做的事情：不恢复任何个人选课或个人行踪，不把课程任务记录当个人课表或独立学生数量，不将合成轨迹、交互和规则写成现场观测事实。旧午间方案的 1,032/442 拆分仅作历史对照，不作为全天人口比例。

完整口径以 `current_model_scope.md` 为准。
