# 两个课程项目

这个仓库并列维护两个研究模块：四平路校园跨学科 Agent 模拟，以及大学路遮荫项目。大学路又分建院交接原项目与我们组的最终原型设计，源文件、数据、结论和预览各自标明来源。

## 项目入口

- [校园跨学科](01_校园跨学科/README.md)：原有四平路校园研究、数据、GIS、GAMA 模型与汇报材料。
- [大学路遮荫](02_大学路遮荫/README.md)：建院交接项目和我们组原型设计两个部分。
- [仓库结构说明](REPOSITORY_STRUCTURE.md)：模块边界、数据来源与预览方式。

网页入口：打开仓库根目录的 `index.html`，或本地启动静态服务器。仓库文件量较大，建议使用 Git 克隆以保留原文件与历史。

## 本地预览

Windows PowerShell 在仓库根目录执行：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8766/`，从导航页进入任一模块。关闭运行服务器的 PowerShell 窗口即可停止。

## GitHub Pages

根目录 `index.html` 可作为静态站点入口。将仓库推送后，在 GitHub 仓库 **Settings → Pages** 选择 **Deploy from a branch**、分支 `main`、目录 `/(root)` 并保存。Pages 发布的是静态页面；Rhino/Grasshopper 模型需在 Rhino 中编辑/重算。

交接资料来源见大学路模块内的清单。原始 `.gh`、CSV 和数据交付 ZIP 保留在仓库；完整汇报包中的可辨认人物照片/视频只保留在本地副本，不公开提交。没有随包提供开放许可文件的资料，继续传播时应保留归属并遵守交接方约定。
