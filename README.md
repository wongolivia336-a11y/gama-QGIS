# 从活动链到空间图谱：同济四平路校园 Agent 模拟

本项目研究“环境科学与工程学科群学生行为与空间关系”，先以四平路校区全域、07:30–17:30 的典型工作日行为模拟识别活动链与空间热点，再从结果中选出值得进一步观察的建筑和时段，进入局部设计研究。

## 给组员：项目现在做到哪里

- 全日模型已从原 NoonScope GAMA 模型派生，模拟时钟为 07:30–17:30，五类 Agent 总数固定为 1,474。五专业分别为环境 400、海洋 384、马克思主义 72、化学 351、公共管理 267。
- 研究范围是同济四平路校区；嘉定、沪西为主的其他学科不进入本轮 Agent 池。
- 原来的 1,032/442 是午间版本按约 30% 抽样后的两类起点人数，只保留作历史对照，不代表全天人口或全天起点。
- 晨间来源、10 栋已确认宿舍分配、校门流入、不同入口分流、活动时段、停留与随机种子均已整理为可追踪的参数与规则；西北二舍未能在确认图层中定位。推导依据见 [全天模拟参数工作簿](02_Data/processed/同济大学全天Agent模拟参数归类_修订版.xlsx) 和 `05_GAMA/full_day/includes/`。
- 仓库原型 `CampusScopeFullDay.gaml` 保留了较早一轮的全天行为框架；新收到的 `submitted_package/TongjiDailyScope.gaml` 已将课程聚合段和教室目的地接入每日合成计划，但仍按专业/时段概率推演，不还原个人选课。课程匹配与代理目的地规则见工程包 README 和核验记录。
- `.qgz` 工程配置可读，但引用的 13 个 GPKG 源文件仍未随工程提供。2026-11-08 收到的全天工程包另含 GeoJSON 导出与预生成路网/日计划；这些包内要素可独立读取并用于所附模型结果核验，不能替代原始 GPKG 的 QGIS 图层与现场核验。
- 飞书 Wiki 的 Demo 附件里有 `同济大学PLAN.DWG`（1.15 MB）和 `CampuScope.zip`（1.56 MB），可见附件中没有 `.gpkg`。本地示例 ZIP 含少量示例 GeoJSON，不是这份 QGIS 工程缺失的完整图层。DWG 可能是源底图，但覆盖范围、坐标系和入口细节尚待检查。
- 用户提供的 `TongjiDailyScope_全天模拟_20261108.zip` 保存了工程包内基线与设施压力测试。2026-11-09 已在本机 GAMA 2025.6.4 实际完成两次 07:30–17:30 运行，并用 OBS 录下 GAMA 窗口；运行日志、主要 CSV、截图、4×回放与全程视频归档于 `07_Presentation/evidence/2026-11-09-gama-run/`。
- 包内 GeoJSON/审计记录核验到 28 栋重点建筑、129 栋背景建筑、337 条道路、257 个节点、40 条建筑入口记录、192 个候选点；宿舍仅 10 栋已定位，西北二舍仍待确认；4 个校门候选中 3 个来自 OSM 推定。原始 GPKG 未到，因此以上是工程包导出层/模型输入的计数，不代表 QGIS 源文件及现场核验已完成。

### 2026-11-09 本机 GAMA 与 OBS 实录

本机全日基线完成 1,474 人、337 条道路、192 个候选点的模拟（seed 42），至 17:30 记录 73,290 条空间观测。设施指标试运行统一开启 192 点、每点 6 席，记录 5,831 次设施进入事件、单点瞬时占用峰值 6。进入事件为人次；逐点去重人数相加为 5,435 个“点位-访客”对，不能当作校区唯一访客。该设施试运行用于验证指标链，最终午休设施点位确定后需要按正式方案重跑。

完整运行过程、CSV、截图、4× GIF/MP4 与 OBS 全程录屏见 [GAMA 实录与结果归档](07_Presentation/evidence/2026-11-09-gama-run/README.md)。

## 研究口径

| 项目 | 当前口径 |
|---|---|
| 研究问题 | 从学生日常活动链提炼校园空间关系，再确定重点空间与后续观察时段 |
| 空间范围 | 同济四平路校区全域 |
| 时间窗口 | 07:30–17:30；先按典型工作日的课表时段分布和行为节律聚合，不锁定单一教学周或星期 |
| 人口 | 1,474 名合成 Agent；五专业总量固定 |
| 课表的作用 | 用于目标专业的时段负荷与教学目的地校准；排课记录不是独立学生，也不重建个人选课/行踪 |
| 空间关注层级 | 标注建筑与入口重点表达；有几何但不属于关注范围的课堂建筑可作灰色背景 |
| 候选点 | 本次工程包导出层已核验 192 个；原始 QGIS GPKG 和现场位置仍待核 |
| 随机性 | 人口生成种子 20261105，GAMA 随机种子 42；比较方案时保持同一人口、路网与种子 |
| 结果解释 | 模拟是有依据、可追踪的行为推演，不是现场实测人流或学生真实轨迹 |

## 仓库结构

- `00_Project_Brief/`：研究范围、课程要求、当前进度。
- `02_Data/processed/`：清理后的聚合表与本轮参数工作簿；不放未脱敏个人课表。

- `05_GAMA/full_day/`：全天 GAML、参数表、人口表、输入约定和生成脚本。
- `AGENTS.md`：所有 Agent 和组员协作时必须遵守的项目说明。

4. 从全校区全天结果识别活动链、跨专业接触、热度与空间差异，再据此选局部建筑和时段开展设计比较。
