# 从活动链到空间图谱：同济四平路校园 Agent 模拟

本项目研究“环境科学与工程学科群学生行为与空间关系”，先以四平路校区全域、07:30–17:30 的典型工作日行为模拟识别活动链与空间热点，再从结果中选出值得进一步观察的建筑和时段，进入局部设计研究。

## 给组员：项目现在做到哪里

- 全日模型已从原 NoonScope GAMA 模型派生，模拟时钟为 07:30–17:30，五类 Agent 总数固定为 1,474。五专业分别为环境 400、海洋 384、马克思主义 72、化学 351、公共管理 267。
- 研究范围是同济四平路校区；嘉定、沪西为主的其他学科不进入本轮 Agent 池。
- 原来的 1,032/442 是午间版本按约 30% 抽样后的两类起点人数，只保留作历史对照，不代表全天人口或全天起点。
- 晨间来源、11 栋宿舍分配、校门流入、不同入口的分流、活动时段、停留与随机种子均已整理为可追踪的参数与规则；推导依据见 [全天模拟参数工作簿](02_Data/processed/同济大学全天Agent模拟参数归类_修订版.xlsx) 和 `05_GAMA/full_day/includes/`。
- 当前 GAML 已采用全天分时活动权重，但尚未将课表的每条排课记录映射为 Agent 的具体课堂时刻/教室。参数表已整理目标专业的课表时段分布；拿到 GIS 建筑主键后再接入聚合课表权重与目的地。模型不复原个人选课。
- `.qgz` 已在本机 QGIS 3.44.15 桌面程序打开。工程配置本身可读；引用的 13 个 GPKG 文件当前缺失，因此 13 个图层都无法载入几何。逐层清单见 [QGIS 检查记录](04_GIS/qgis_project_audit_20261108.json) 和 [数据补齐说明](04_GIS/qgis_data_request.md)。这不是 `.qgz` 格式错误。
- GAMA 已完成全日模型编译；1,474 个 Agent 的机制烟雾运行推进到 17:30。该烟雾运行用的是旧 NoonScope 示意底图，只验证模型时钟、人口载入和状态结束流程，不能作为四平路全校区空间结果。
- 当前还没有基于这份 QGIS 工程几何的正式全校区运行。收到配套 GPKG 后，才能核验楼栋、入口、校门、路网连通和干预候选点的实际数量与位置。

## 研究口径

| 项目 | 当前口径 |
|---|---|
| 研究问题 | 从学生日常活动链提炼校园空间关系，再确定重点空间与后续观察时段 |
| 空间范围 | 同济四平路校区全域 |
| 时间窗口 | 07:30–17:30；先按典型工作日的课表时段分布和行为节律聚合，不锁定单一教学周或星期 |
| 人口 | 1,474 名合成 Agent；五专业总量固定 |
| 课表的作用 | 用于目标专业的时段负荷与教学目的地校准；排课记录不是独立学生，也不重建个人选课/行踪 |
| 空间关注层级 | 标注建筑与入口重点表达；有几何但不属于关注范围的课堂建筑可作灰色背景 |
| 候选点 | QGIS 图层标签写“约 50m”布点；真实要素数尚不可读，192 个不作为既定数量 |
| 随机性 | 人口生成种子 20261105，GAMA 随机种子 42；比较方案时保持同一人口、路网与种子 |
| 结果解释 | 模拟是有依据、可追踪的行为推演，不是现场实测人流或学生真实轨迹 |

## 仓库结构

## 继续运行的步骤

1. 收到 QGIS 工程引用的 GPKG 文件后，放在同一数据包里；先对照 `04_GIS/qgis_data_request.md` 检查文件名和图层。
2. 核对楼栋名称及宿舍分栋、校园校门和建筑楼门、坐标系、路网连通、干预候选点要素数；尤其确认暂列的“西北二舍”与实际楼名对应关系。
3. 按 `05_GAMA/full_day/includes/全天网络输入约定.md` 生成模型输入。不同楼栋各自保留主键，建筑入口与校园校门是两类对象。
4. 在 GAMA 中打开 `05_GAMA/full_day/models/CampusScopeFullDay.gaml`，先用空设施基线运行，再按明确选定的设施方案比较；种子与人口表不变。
5. 全校区结果用于发现活动链、跨专业接触、热度和空间差异；再基于证据收敛到重点建筑与某个时段，开展局部模拟和设计比较。

模型运行与结果边界见 `05_GAMA/full_day/run_instructions.md`。
