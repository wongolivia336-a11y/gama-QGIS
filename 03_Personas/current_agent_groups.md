## 人口与活动边界

- 五专业总量是全日模型的固定 Agent 数；不会由课程任务数或排课段数再次扩张。
- 用户提供的排课表用于推导日内课程负荷与目的地比例；它不是个人选课表的复原，也不用于生成真实学生身份。
- 当前代码使用一般日内活动权重，并保留用户给出的午间规则；课程记录与具体 Agent 的教室分配尚待接入。
- 首轮全日来源按 1,179 名宿舍起点与 295 名校门起点分配。各专业内部按统一比例分配，避免没有证据时虚构专业—宿舍偏好。
- 宿舍以 11 栋独立建筑 key 建模，当前为便于首轮比较而近似均分；西北二舍名称和各栋真实容纳量待 QGIS/楼宇资料核验。
- 上述行为角色是透明的模型规则，所有具体数值见 `02_Data/processed/同济大学全天Agent模拟参数归类_修订版.xlsx` 和 `05_GAMA/full_day/includes/full_day_activity_profile.json`。
