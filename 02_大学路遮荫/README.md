# 大学路遮荫

本模块分成两个部分：

1. [建院交接原项目](01_建院交接原项目/README.md)：保留 Grasshopper 源文件、交接数据和原始浏览器交互预览。
2. [我们组最终原型](02_我们组最终原型/README.md)：使用经过核验的数据，建立有证据支撑的行为分析与自然形态遮荫方案。

## 在线/本地入口

- 打开本目录的 `index.html`，可分别进入原项目和我们组的原型入口。
- 本地从仓库根启动 `python -m http.server 8766 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8766/02_大学路遮荫/`。
- 原交互页使用预打包数据在浏览器中展示。我们组的页面会明确标注方法和模型的完成状态，不把概念框架呈现为最终实物。

## 研究衔接

我们组沿用交接项目中可复核的环境数据，重新建立“行为证据 → 遮荫需求 → 形态规则 → 性能评估”的关系。环境/辐射字段的坐标、单位、时段与行为数据的对应关系核验后再进入模型；行为类别由明确理论框架和观察证据支持，不从外貌或衣着推断。

建院原件的公开使用范围以交接约定为准。清单和校验值见 `01_建院交接原项目/source/manifest.md`。
