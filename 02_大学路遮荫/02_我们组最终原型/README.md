# 我们组最终原型

本模块承接大学路环境数据，建立我们自己的行为依据、形态规则和原型预览。建院交接原型仍保存在 [`../01_建院交接原项目/`](../01_建院交接原项目/) 供对照；本目录里的分析、参数和模型属于我们组的工作。

## 设计方向

遮荫形态以自然生长的树冠/枝叶逻辑为出发点，回应公共空间步行、短暂停留和持续停留等不同情境。具体活动类别与形态映射尚需通过文献和观察证据确定；在证据和参数映射明确前，页面不会把概念框架标成最终设计。

## 工作链

```text
行为证据与理论分类
        ↓
地点、时段、活动类型、停留时长
        ↓
经核验的辐射/热暴露字段
        ↓
遮荫需求与空间优先级
        ↓
有机顶棚几何参数
        ↓
遮荫、通行净空、视线和可达性评估
```

## 子目录

- `research/`：行为分类依据、文献和观察编码。
- `data/`：交接数据的字段、坐标/单位/时间核验及加工记录。
- `design/`：需求、设计假设、形态参数和性能评价。
- `model/`：我们组自己的 Rhino/Grasshopper 源文件与导出版本。
- `preview/`：网页原型入口。当前为研究与设计流程的起始页，尚不是最终三维模型。

## 当前边界

- 交接数据可描述环境暴露；行为类别需要独立依据，不能仅从辐射栅格推断。
- 设计规则需要记录输入证据、转换方式、输出参数和验证指标。
- 所有模型输出标注为模拟/设计推演，不表述为现场验证。
- 暂无本组 Grasshopper 几何文件；新建模型后存入 `model/`，同时在本 README 记录软件版本、输入和导出日期。
